MySQL + Python

Bases de datos desde aplicaciones Python

¿Qué es MySQL?

Sistema gestor de bases de datos relacionales para almacenar, consultar y administrar información.

¿Qué aporta Python?

Permite crear programas que procesan información y se comunican con bases de datos.

¿Cómo se conectan?

Mediante conectores como mysql-connector-python, Python puede ejecutar consultas SQL.

Flujo

Python → Conector MySQL → Base de datos → SQL → Resultados → Python
