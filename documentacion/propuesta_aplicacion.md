# Propuesta de aplicación

## Sistema de gestión de productos y ventas

### Entidades
- Producto
- Categoría
- Usuario
- Venta
- DetalleVenta

### Relaciones
- Una categoría puede tener varios productos.
- Un usuario puede realizar varias ventas.
- Una venta puede tener varios detalles.
- Cada detalle corresponde a un producto.

### Requisitos funcionales
Registrar, consultar, modificar y eliminar productos; registrar ventas; buscar información y generar reportes.

### Requisitos no funcionales
Seguridad, facilidad de uso, rapidez, disponibilidad y respaldo de la información.
