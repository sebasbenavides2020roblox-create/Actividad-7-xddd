# Tipos de datos

**INT:** números enteros. Ejemplo: 17.

**VARCHAR:** cadenas de texto de longitud variable. Ejemplo: "Juan".

**DATE:** fechas. Ejemplo: 2026-09-30.

**DECIMAL:** números decimales con precisión. Ejemplo: 2500000.50.

**BOOLEAN:** valores verdadero/falso.

**TEXT:** textos largos.
